## ✅ Approche 8 : Grassroots Admin Partnership — **CHOISIE**

**Doc** : [01_GRASSROOTS_ADMIN_PARTNERSHIP.md](./01_GRASSROOTS_ADMIN_PARTNERSHIP.md)

**Concept** : Infiltrer 30-40 Discords gaming français, bâtir relations authentiques avec admins, proposer giveaways DANS leurs serveurs (admin face publique, Drop & Loot opère background).

| Aspect | Détail |
| ------ | ------ |
| Timeline | 6 mois (phases) |
| Budget | €3-4k total (€500-600/op) |
| Discrétion | ✅✅ Invisible publiquement |
| Viral Growth | ✅✅ Chaîne de confiance |
| Control | ✅ Total |
| Quality | ✅ Chaque participant verified |
| Prestige | ✅ Exclusive croît |
| Status | ✅✅ **CHOISIE** |

**Raison choix** :
- ✅ Approche discrète (demande user)
- ✅ Prestige naturel (exclusive clubs)
- ✅ Croissance virale saine (amis invitent amis)
- ✅ Contrôle total process
- ✅ Budget raisonnable (€3-4k sur 6 mois)

**Risque minimisé** :
- Infiltration authentique = pas apparent comme « marketing »
- Community Fund = admins deviennent advocates
- Founder's Circle = rareté = prestige amplifié

## Approche Bonus : Combinaison (Grassroots + Media)

**Hybrid approach** : Exécuter Grassroots (Op1-3), PUIS faire Media First (mois 4-6).

```txt
Mois 1-3 : Grassroots (Op1-3)
├─ 300-500 participants
├─ 3 admins validant
├─ Case studies prêts
└─ Credibility = « 3 communautés réussies »

Mois 4 : Media Outreach
├─ Pitch journalistes avec 3 cas d'études réels
├─ Story angle : « French startup with 3 community validations »
├─ Probability d'acceptance : 80%+ (cas réels > hypothétique)

Mois 5-6 : Launch Public
├─ Journalist article publié
├─ Op4-5 lancées publiquement
├─ Combined credibility : Grassroots + Press
```

**Avantage** : Best of both. Grassroots pour private momentum, Media pour public launch.
