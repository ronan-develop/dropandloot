# Stratégie Grassroots Admin Partnership

> Infiltrer les communautés Discord existantes, bâtir relations avec administrateurs,
> proposer collaborations gagnant-gagnant pour des giveaways transparents.
> Zéro budget, zéro exposition publique, maximum crédibilité organique.

---

> ⚠️ **Promotion non identifiée et avantages aux relais d'influence (audit 2026-09-26)** :
>
> - Rejoindre des serveurs « anonymement, en tant que joueurs » puis y promouvoir Drop & Loot sans révéler
>   la qualité de professionnel est une pratique commerciale trompeuse réputée telle : « se présenter
>   faussement comme un consommateur » (art. L.121-4, 21° C. conso), déloyale au sens de l'art. L.121-1.
>   Déclarer d'emblée l'appartenance à Drop & Loot dans tout échange à visée commerciale.
> - L'admin qui annonce le giveaway contre un avantage (lot pour sa communauté, part négociée, prestige)
>   agit à titre onéreux (art. 1 loi n° 2023-451 du 9 juin 2023, qualification à confirmer) : mention
>   « Publicité » ou « Collaboration commerciale » obligatoire (art. 5-2 de la loi, version au 2024-11-08),
>   sinon pratique trompeuse par omission (art. L.121-3 C. conso). Les témoignages d'admins ainsi
>   rémunérés ne peuvent être présentés comme « non payés ».
> - Le tirage doit rester gratuit, sans obligation d'achat (art. L.320-1 CSI). Voir
>   `business/03_JEUX_CONCOURS_CADRE_LEGAL.md`.

## Executive Summary

**Concept:** Vous n'êtes pas la marque. Les admins Discord sont.

**Model:**
1. Rejoignez 10-20 Discords gaming français (anonymement, en tant que joueurs)
2. Bâtissez relation authentique avec admins (2-3 mois)
3. Proposez collaboration : « Organise un giveaway transparent pour ta commu. On gère tout. »
4. Exécutez giveaway DANS leur Discord (pas le vôtre)
5. Vous restez invisibles (juste opérateurs technique)
6. Chaque succès = prochain admin plus facile

**Résultats après 6 mois:**
- 10+ giveaways réussis
- 10+ admins qui vous connaissent + validez
- 1000+ gamers ayant participé
- Zéro exposition publique
- Crédibilité organique maximale

**Investissement:** €3-4k total (€500-600 par giveaway × 6-8)

### Phase 1 : Reconnaissance (Semaines 0-2)

#### Étape 1.1 : Identifier Discords Cibles

**Où chercher :**

```
Sources principales:
├─ Reddit (r/gaming, r/france, r/esports, subreddits jeux)
│  └─ Bios des utilisateurs = liens Discord
│
├─ Google (« discord gaming france », « discord [jeu populaire] »)
│  └─ Discord.me, Disboard, Discord server listings
│
├─ Twitter (gamers français)
│  └─ Cherchez #gaming #discord #esports + liens en bio
│
├─ TikTok (gaming français)
│  └─ Liens Discord dans bios creators
│
└─ Discord Explorer
   └─ Search « gaming », filter France
```

**Critères de Sélection :**

```
✓ Bon serveur = 1k-10k membres
  └─ Sweet spot : assez gros (impact), pas trop (admin pas débordé)

✓ Actif
  └─ Messages réguliers, pas serveur mort

✓ Modéré
  └─ Règles claires, spam éliminé, admin présent

✓ Sérieux
  └─ Joueurs vrais, pas bots, pas toxic

✓ Diversifié
  └─ Multi-jeux (meilleur qu'un seul jeu)

❌ Mauvais serveur = 100k+ membres
  └─ Admin trop occupé, bureaucratie, moins personnel
```

### Phase 2 : Infiltration (Semaines 1-8)

#### Étape 2.1 : Rejoindre (Naturellement)

```
Par serveur, timeline de 7-14 jours:

Jour 1:
├─ Rejoindre Discord
├─ Lire #règles, #annonces, #general
├─ Comprendre: culture, jeux populaires, admins, bots
├─ Silent lurking (pas de message)

Jours 2-3:
├─ Messages simples (#general chat, casual)
├─ Répondre questions d'autres (helpful)
├─ Pas de promo, juste participation normale

Jours 4-7:
├─ Participation plus active (mais toujours normale)
├─ Exemple: quelqu'un demande « quel GPU? »
│         → vous répondez détaillé
├─ Exemple: discussion jeu → vous participez
├─ Votre goal: être vu comme « valued member »

---

Tone: Vous êtes joueur passionné, point.
Pas de hype, pas de "j'ai une startup"
Juste: authentique, utile, normal
```

#### Étape 2.2 : Observation Admin

```
Pendant 2-4 semaines en lurk/participate:

Repérez:
├─ Qui est l'admin principal? (fondateur, leader)
├─ Admin secondaires? (helpers)
├─ Style admin: strict? cool? transparent?
├─ Valeurs admin: communauté d'abord? modération? fair?
├─ Pain points admin: spam? low engagement? modération fatigue?

Exemple observation:
├─ « Okay everyone, we're cracking down on scam links » 
│  → Admin cares about safety
├─ « Community vote on next event »
│  → Admin values input
├─ « Sorry for late moderation, busy IRL »
│  → Admin is human, probably overworked
└─ « We don't tolerate scams or misleading posts »
   → Perfect alignment with your mission

---

Goal: Understand admin psychologically
└─ Pourquoi ils run ce serveur?
└─ Qu'est-ce qui les frustre?
└─ Comment les aider?
```

### Phase 3 : Connexion (Semaines 4-8)

#### Étape 3.1 : Devenir Utile

```
Actions pour être remarqué:

1. Modération light
   ├─ Reportez les messages spam (help moderation)
   ├─ Welcome newcomers (good vibes)
   ├─ Clarify rules when people ask
   └─ Admin sees: « This person helps »

2. Expertise sharing
   ├─ Quelqu'un demande conseil gaming → réponse détaillée
   ├─ Question technique → thorough answer
   ├─ Partage expérience (« J'ai joué 5 ans à [jeu], voici... »)
   └─ Admin sees: « This person knows their stuff »

3. Community energy
   ├─ Positif tone (no negativity, no drama)
   ├─ Celebrate wins (« Congrats on your win! »)
   ├─ Inclusive (« Anyone want to play together? »)
   └─ Admin sees: « This person is good for culture »

---

Expected admin reaction (after 3-4 weeks):
├─ Notices you in active members
├─ Might give you a role (« Trusted Member » or « Helper »)
├─ Or just: trust that you're solid

Goal achieved: You're no longer unknown.
```

#### Étape 3.2 : Message Privé (Week 4-5)

**Timing:** Only after you're established (30+ messages, visible member)

**Template (PERSONNALISÉ par admin/serveur) :**

```
Subject: Idea for [ServerName]

---

Salut [Admin First Name],

Ça fait quelques semaines que je suis sur ton serveur. 
J'aime vraiment ce que tu fais ici — c'est rare une commu aussi sérieuse, 
sans spam et arnaque.

J'ai pensé à quelque chose qui te plaira maybe (zero pressure if not).

On travaille sur des giveaways 100% transparents pour gaming community.
Tirage constaté par commissaire de justice, process relu par avocat, zéro arnaque.

Ton serveur = parfait pour tester un truc comme ça.
Idée: tu organises un giveaway pour ta commu.
On gère la technique + certification + lot. 
Toi tu as la prestige, ta commu gagne un cool cadeau.

Pas de coût pour toi, pas de risque.
Juste de la transparence + bonne PR pour ton serveur.

Intéressé pour une call de 15 min? (Even if not, no worries!)

À bientôt,
Ronan

---

Personnalisation checklist:
✓ Mention quelque chose du serveur (culture, admin style)
✓ Compliment sincère (non-obvious, specific)
✓ « No pressure » (you mean it)
✓ Brief (15 min, not hours)
✓ Humble tone (not salesy)
✓ Clear ask (call? discussion?)
```

### Phase 4 : Conversation Admin (Week 5-6)

#### Étape 4.1 : Call Structure (15 min)

```
00:00-02:00 | Rapport & merci
├─ « Merci d'avoir taken the call »
├─ « Ton serveur est vraiment cool, j'aime l'énergie »
└─ Compliment spécifique (« J'ai vu comme tu handles spam, c'est clean »)

02:00-05:00 | Problem statement (RELATABLE)
├─ « I imagine you deal with this: lots of scam giveaways »
├─ « Your members probably complain: fake lots, no delivery, data theft »
├─ « Happens in gaming all the time »
├─ Admin will: « Ouais, c'est fou... »

05:00-10:00 | Offer (CLEAR VALUE FOR THEM)
├─ « We built Drop & Loot: legit giveaway platform »
├─ « What we do: handle everything (legal, transparent, certified) »
├─ « What we ask: can you organize giveaway for your community? »
│
├─ Value for admin:
│  ├─ Your community gets cool prize (prestige for you)
│  ├─ Shows you care about members
│  ├─ Engagement boost (exciting event)
│  └─ Zero work for you (we handle it all)
│
└─ « Interested? »

10:00-13:00 | Logistics (DETAILED)
├─ If yes: « Cool! Here's how it works »
│  ├─ Timeline: when?
│  ├─ Lot details: what prize?
│  ├─ Your role: you announce, we handle technical
│  ├─ Participants: your members register in our system
│  └─ Tirage: we show you everything (transparent)
│
├─ « Any concerns? Questions? »
└─ Address each one (be flexible, solve problems)

13:00-15:00 | Close (LIGHT)
├─ « Think about it, no rush »
├─ « We can do a small test first if you want »
├─ « Either way, happy to help your community »
└─ « Let me know! »
```

#### Étape 4.2 : Répondre Objections

```
Objection 1: « Sounds cool but how do I know this is real? »
Response: « Great question. Here's what you should know:
  - We're registered with SIREN/SIRET (I'll send you)
  - Commissaire de justice attends every draw (our choice: not legally required since the
    loi n° 2014-1545 of 20 Dec. 2014, art. 54)
  - Avocats reviewed our process (I'll share letter)
  - Everything is documented + transparent
  
  You can literally watch us do it. No hidden magic. »

Objection 2: « What's in it for you? »
Response: « Honest answer: we're building credibility.
  You're not our first, but we want to be the transparent option.
  You validate us, we validate you.
  Both of us win.
  
  We're not trying to make money off giveaways,
  we're trying to fix the market. »

Objection 3: « What if something goes wrong? »
Response: « Good question. Worst case:
  - Delivery delay → we cover extra insurance + compensation
  - Participant issue → we handle support
  - You're not liable — we are.
  
  We've thought through this. We're insured. »

Objection 4: « Requires my community to give data? »
Response: « They only give:
  - Discord handle (they have anyway)
  - Email (for notification + delivery)
  
  We delete all data 30 days after.
  RGPD compliant, audited by lawyers.
  I'll send you the full policy. »

Objection 5: « I need payment / share of revenue »
Response: « I hear you. Let me share what we're thinking... »
(See next section on compensation structure)
```

## Budget & Coûts

### Par Giveaway

```
Fixed cost:
├─ Huissier: €400-600
├─ Assurance: €50-100
│  └─ Lot insurance (if value > €500)
├─ Shipping: €50-150
│  └─ Admin might share
└─ Admin potential share: -€50 to -€200 (negotiated)

Variable cost:
├─ Lot: €500-2000 (depending on what you source)

---

How to minimize lot cost:

Option A: Borrow
├─ Friends' gaming gear (GPU, peripherals)
├─ Return after giveaway
├─ Cost: €0 (trust required)

Option B: Trade
├─ « I'll run your giveaway if you donate gaming gear »
├─ Contact: small streamers, gaming shops, game publishers
├─ Cost: €0 (time to find partners)

Option C: Used / refurb
├─ RefurbGPU, gaming resale shops
├─ €200-500 instead of €1000
├─ Still valuable to winners

Option D: Game codes
├─ Cheap giveaway: €10-50 game codes
├─ Works if community is into specific games
├─ Cost: €20-100 total

Option E: Mix
├─ Month 1: Borrow (€0)
├─ Months 2-3: Trade (€0)
├─ Months 4-6: Buy cheap + negotiate with admins (€200 total)

---

Potential cost reduction:
├─ Month 1: €600 (huissier full cost)
├─ Month 2: €300 (split huissier with Month 1?)
├─ Month 3+: €200 (share resources, cheaper lots)

Sustainability:
├─ If admins fund lots: cost drops to just huissier (€400-500/month)
├─ Possible after month 3-4 when proven
```

## Avantages Clés

✅ **Zero public exposure**
- You're invisible (admins are faces)
- No founder Twitter drama
- No viral pressure

✅ **Authentic validation**
- Real admins, real communities, real results
- Not paid testimonials (faux si l'admin reçoit un avantage : voir avertissement en tête)
- Community members vouch for you

✅ **Repeatable playbook**
- Each giveaway teaches you something
- 2nd, 3rd, 10th are easier
- System compounds

✅ **Organic growth**
- Admins talk to each other (« We did a giveaway... »)
- Word-of-mouth spreads naturally
- Viral but controlled

✅ **Budget realistic**
- €3-4k for 6 months (if borrow lots)
- Can start with €500-600
- Scales down with each giveaway

✅ **True grassroots**
- Community-driven, not marketing-driven
- People believe in it organically
- When you launch publicly: « 1000+ people already tested »

## Risques & Mitigations

| Risque | Mitigation |
|--------|-----------|
| Admin says no | 30-40 targets, expect 20% accept → 6-8 yes |
| Giveaway breaks | Huissier + insurance covers, admin protected |
| Participant complains | Livraison guarantees, refund policy clear |
| Admin ghosted after giveaway | Follow up, offer next giveaway, maintain relationship |
| Budget runs out | Start with 1 borrow, don't commit to 10 upfront |
| Admins ask for too much | Negotiation structure (see next section) |
