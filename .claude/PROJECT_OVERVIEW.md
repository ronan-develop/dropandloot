# Project Overview — Drop & Loot

Vue d'ensemble complète du projet.

---

## 🎯 Objectif

Créer une plateforme légale et transparente de ventes de T-shirts + tirages au sort, structurée en 3 entités :
1. **Association loi 1901** — Propriétaire des actifs communs (marque, domaine, base clients)
2. **Auto-entrepreneur A (Ronan)** — Porte les opérations commerciales
3. **Auto-entrepreneur B (Johann)** — Porte les opérations commerciales

---

### Entité 1 : Association "Maison Drop & Loot"

- Gère : Compte courant, redistribution équitable 50/50

### Entité 2 : GIE "Drop & Loot Studio"
- Gère : Opérations commerciales (vente T-shirts, jeux concours)

### Entité 3 & 4 : Auto-Entrepreneurs (Conservent leur statut)

## 💰 Modèle économique

**Compte courant avec redistribution équitable :**

```
Opération 1 (100k CA) : Ronan encaisse → déclare → paie charges → verse 42k net à asso
Opération 2 (60k CA)  : Johann encaisse → déclare → paie charges → verse 25k net à asso

Asso calcule : 42k - 25k = 17k d'écart → redistribue 8,5k chaque sens
Résultat : Ronan 33,5k + Johann 33,5k = 50/50 final
```

**Légalité :** Chacun déclare 100% du CA réel → pas de "société de fait"

## 🎮 Stratégie Gaming

**Obstacles identifiés :**
1. "C'est un scam" — Faux giveaways omniprésents
2. "Qui êtes-vous ?" — Anonymat = suspicion
3. "Mes données ?" — Peur RGPD
4. "Tirage truqué ?" — Méfiance RNG
5. "Non-livraison" — Cas fréquents
6. "Marque inconnue" — Pas de track record

**Solutions :**
- Documentation légale publique
- Huissier pour chaque tirage
- Lot physiquement vérifiable
- Politique RGPD transparente
- Livraison avec suivi public
- Micro-influenceurs testeurs
