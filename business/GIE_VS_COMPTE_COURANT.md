# GIE vs Compte Courant — Analyse légale

Comparaison des deux modèles avec légalité URSSAF.

---

## ⚖️ Le problème: Risque "Société de fait"

**Modèle actuel (Compte courant)** :
- Ronan encaisse CA → déclare URSSAF → verse bénéfice net à asso
- Johann encaisse CA → déclare URSSAF → verse bénéfice net à asso
- Asso redistribue pour égaliser 50/50

**Risque URSSAF** :
L'URSSAF peut requalifier cette structure en **"société de fait"** parce que:
- Partage régulier de bénéfices ✗
- Gestion commune des finances (compte courant) ✗
- Profit-sharing entre AE ✗

**Conséquence si requalification** :
- ❌ Perte du statut auto-entrepreneur
- ❌ Cotisations réévaluées rétroactivement
- ❌ Pénalités + intérêts
- ❌ Audit URSSAF

---

## ✅ Solution légale: GIE (Groupement d'Intérêt Économique)

### 📜 Cadre légal

**Code du Commerce - Livre VI** ([source officielle](https://www.legifrance.gouv.fr/codes/texte_lc/LEGITEXT000005634379/)):

> "Un groupement d'intérêt économique est constitué entre des personnes physiques ou morales afin de mettre en œuvre les moyens nécessaires à l'exercice d'activités concourant à un but commun"

**Spécificités GIE** :
- ✅ Les membres gardent leur **statut auto-entrepreneur**
- ✅ Partage de frais et ressources = **légal**
- ✅ Accepté explicitement par l'URSSAF
- ✅ Structure souple et adaptée

**Texte de référence** : [URSSAF sur GIE et auto-entrepreneurs](https://www.urssaf.fr/accueil/choisir-forme-juridique/groupement-interet-economique-gie.html)

## 📊 Modèle GIE: Comment ça marche

### Structure

```txt
GIE "Drop & Loot"
├── Ronan (AE A) — Associé
├── Johann (AE B) — Associé
└── Activité commune: Vente T-shirts + tirage
```

### Fonctionnement

**Opération 1 (Ronan encaisse)** :
1. Ronan facture client au nom du GIE
2. Ronan encaisse CA (10 000€)
3. Ronan déclare 100% à l'URSSAF (auto-entrepreneur)
4. Ronan paie charges (12.3%)
5. Ronan verse bénéfice net au GIE

**Opération 2 (Johann encaisse)** :
- Même procédure

**Redistribution (légale dans le GIE)** :
- GIE peut redistribuer les résultats aux associés
- ✅ C'est explicitement autorisé
- Pas de risque "société de fait"

### Avantages GIE

| Point | Détail |
|------|--------|
| **Légalité** | Code Commerce L.211-1 et suivants |
| **Statut AE** | Conservé pour chaque associé |
| **Frais partagés** | Légalement autorisés (bureaux, outils, etc.) |
| **Redistribution** | Légale et documentable |
| **Simplicité** | Moins bureaucratique qu'une SARL |
| **Flexibilité** | Règlement intérieur adapté |

## 📋 Étapes pour passer en GIE

### 1. Rédiger le contrat GIE (~400€ avec avocat)

Éléments clés:
- Objet: "Vente de T-shirts + tirages au sort"
- Apports: Chacun apporte son activité
- Résultat: Modalités de répartition
- Sortie: Conditions de départ

### 2. Enregistrer auprès de la Sous-Préfecture (~150€)

- Déclaration GIE
- Numéro SIRET automatique
- Publication au JO

### 3. Déclarer aux impôts

- GIE transparent fiscalement
- Chacun déclare son CA (pas de changement)
- Charges URSSAF: identiques

### 4. Ouvrir compte GIE

- Compte bancaire au nom du GIE
- Facilite les versements/redistribution

## 🎯 Modèle optimal: Asso + GIE (Hybride)

### Architecture Drop & Loot

```txt
┌─────────────────────────────────────┐
│  Asso "Maison Drop & Loot"          │
│  - Propriétaire: Marque INPI        │
│  - Propriétaire: Domaine            │
│  - Propriétaire: Réseaux sociaux    │
│  - Peut faire: Événements           │
└──────────────┬──────────────────────┘
               │ (Contrat partenariat)
┌──────────────▼──────────────────────┐
│  GIE "Drop & Loot"                  │
│  - Associés: Ronan (AE A)           │
│  - Associés: Johann (AE B)          │
│  - Gère: Opérations commerciales    │
│  - Redistribue: Résultats           │
└─────────────────────────────────────┘
```

### ✅ Avantages du modèle hybride

1. **Propriété intellectuelle sécurisée** : Asso détient marque + domaine
2. **Sécurité juridique** : Zéro risque URSSAF avec GIE
3. **Pérennité** : Si GIE se dissout, asso récupère tous les actifs
4. **Évolutivité** : Asso peut accueillir partenaires, faire événements
5. **Flexibilité** : Opérations commerciales claires (GIE) vs patrimoine (Asso)
6. **Protection des assets** : La marque ne dépend pas des relations commerciales

### ⚖️ Comparaison 3 modèles

| Aspect | Asso seule | GIE seul | **Asso + GIE** |

| **Si quelqu'un part** | 🟡 Complexe | 🔴 Risqué (marque au GIE) | 🟢 Asso récupère tout |
| **Événements communautaires** | 🟢 Facile | 🟡 Pas prévu | 🟢 Asso fait |
| **Coût initial** | 💰 ~350€ | 💰 ~550€ | 💰 ~900€ |
| **Coût annuel** | 💰 ~50€ | 💰 ~0€ | 💰 ~50€ |

| **Acceptation URSSAF** | 🟡 Risque | 🟢 Explicite | 🟢🟢 Explicite |

## 🎯 Recommandation FINALE

### Pour Drop & Loot: **Modèle Asso + GIE**

**Pourquoi c'est le meilleur choix** :

1. ✅ **Sécurité juridique** : Zéro risque URSSAF (GIE explicitement légal)
2. ✅ **Protection marque** : L'asso la possède (ne dépend pas du GIE)
3. ✅ **Pérennité** : Si quelqu'un part, asso récupère marque + domaine
4. ✅ **Légalité explicite** : Code Commerce (GIE) + Loi 1901 (Asso)
5. ✅ **Évolutivité** : Capacité à scaler, intégrer partenaires, faire événements
6. ✅ **Flexibilité** : Opérations claires, patrimoine protégé

**Budget total recommandé** :
- Asso (création + statuts): 300€
- Marque INPI (2 classes): 230€
- GIE (création + contrat): 500€
- **TOTAL: ~1 030€**

**Amortissement**: ~200€/an sur 5 ans = très rentable

### Contrat partenariat Asso ↔ GIE

Doit préciser:
- Asso met à disposition: marque, domaine, réseaux
- GIE utilise légalement pour opérations
- Contributions GIE → Asso (optionnel, sympa de faire 10% des bénéfices)
- En cas dissolution GIE: tous les actifs retournent à l'asso
- En cas départ membre: clauses de sortie claires

## ⚠️ Points de vigilance

1. **Contrat GIE bien rédigé** : Essentiel
2. **Comptabilité régulière** : Documenter la répartition
3. **Pas de lien de subordination** : Chacun reste indépendant
4. **Factures distinctes** : Au nom du GIE (pas des AE)
5. **Compte GIE** : Facilite la transparence
